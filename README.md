# Weather Diary

**Автор:** Дмитрий Трубин

## Описание

Приложение *Weather Diary* — это простой GUI‑инструмент для ведения дневника погоды. Позволяет:
* добавлять записи с указанием даты, температуры, описания и наличия осадков;
* просматривать все записи в табличном виде;
* фильтровать данные по дате и температуре;
* сохранять и загружать записи в формате JSON.

## Технологии

* Язык программирования: Python 3.6+
* GUI‑библиотека: Tkinter (стандартная библиотека Python)
* Формат хранения данных: JSON
* Система контроля версий: Git
